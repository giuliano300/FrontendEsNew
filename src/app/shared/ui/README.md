# Shared UI

Componenti standalone riusabili per i pattern comuni dell'app.

- `UiTourRestartComponent`: bottone standard per riavviare i tour.
- `UiAlertComponent`: feedback error/success con icona, messaggio e testo forte opzionale.
- `UiEmptyStateComponent`: messaggio unico per liste o tabelle vuote.
- `UiLoadingStateComponent`: spinner testuale riusabile.
- `UiSubmitButtonComponent`: bottone submit con stato loading integrato.

Import consigliato:

```ts
import { UiAlertComponent, UiEmptyStateComponent } from '@app/shared/ui';
```
